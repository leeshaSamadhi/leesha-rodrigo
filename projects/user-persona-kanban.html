User Persona and Kanban Approach

Miro Requirement Elicitation Requirement Gathering Project Management

Objective

The project aimed to build a user persona, user stories and a Kanban board for an example makeup brand called MASQUE. A user persona adds great value to a business when it comes to identifying the target audience, including their demographics, goals, behaviours, motivations and frustrations.

These help companies create better designs and use data effectively by keeping real user needs front and centre.

Context

Example Makeup brand, MASQUE, on a journey to make a modern analytics platform to strategise their data, existing ecommerce platform and marketing efforts.

The ultimate goal is to explore growth strategies to scale internationally and deepen customer loyalty through personalisation, data-driven marketing, and inventory optimisation. Stakeholders: Venture Capital Partner, CEO, Chief Data Officer, Chief Marketing Officer, Industry Product Lead, Makeup Influencer, Pharmacy Owner, Beauty Therapist, Operations Manager (Logistics), Regulatory Compliance Officer.

Methodology

This project focused on creating user personas and user stories for each stakeholder for the analytics platform that MASQUE plans to launch. A Kanban approach is taken to list the created user stories, visualising the Agile approach in project management.

Two user stories are created for each stakeholder, totalling 20 user stories. Each user story has acceptance criteria written using the Given-When-Then concept. And, to get the best out of Miro, tags and statuses are used to categorise the user stories dedicated to each stakeholder.
